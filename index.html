如何將遊戲架設為公開網站？

3 分鐘免費上線，任何人都能遊玩！

方法一：使用 Vercel 或 Netlify（最簡單）

  1. 把這個單一 HTML 檔案檔名存為 index.html。
  2. 註冊並登入 Vercel 或 Netlify。
  3. 直接將包含 index.html 的資料夾拖拽放置進去。
  4. 完成！數秒內即可獲得免費的網址（例如 my-clicker.vercel.app）。

方法二：使用 GitHub Pages（完全免費永久託管）

  1. 在 GitHub 新建一個公開儲存庫 (Repository)。
  2. 上傳本檔案並命名為 index.html。
  3. 前往儲存庫的 Settings -> Pages。
  4. 把 Source 設定為 main branch 並儲存即可發布！
