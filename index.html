免費架設到網站教學

只需 3 分鐘即可發布成為全球可玩的公開網站

方法一：使用 GitHub Pages (推薦)

  1. 在 GitHub 建立一個新的公開儲存庫 (Repository)。
  2. 把這個 index.html 檔案上傳到儲存庫中。
  3. 進入儲存庫的 Settings > Pages，Source 選擇 main 分支後儲存。
  4. 約 1 分鐘後即可獲得免費的專屬遊戲網站網址！

方法二：使用 Vercel 或 Netlify

  1. 註冊免費 Vercel / Netlify 帳號。
  2. 直接將包含這個 index.html 的資料夾拖曳上傳。
  3. 幾秒內即可自動產生帶有 HTTPS 的正式網址！
